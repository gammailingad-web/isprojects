Monitoring types

Fields for each monitoring type

One field per line: Label | type | options | *. Types: text, textarea, number, date, select. For select, list the choices separated by commas. Add * at the end to make a field required. Date and Branch are always included. ISRF is pre-filled with its standard fields and can be edited too (keep the labels Error type, Documents damaged and Problem details to keep showing existing data; leave the options of Error type blank to use the Error types list). A new monitoring with no fields yet uses the ISRF fields. Do not rename a field once records exist; add a new one instead.
Example: Vendor | text | * and Category | select | Hardware, Software, Network
