Messaging

Email works through your Google account (about 100 recipients per day on a free account). SMS can always be opened in the phone's Messages app. To send SMS directly from the system, connect a gateway: a free Android phone gateway (SMSGate app, sends from your own SIM) or Semaphore (paid, needs approval).

Procurement Request (PRF) setup

Configure who may approve and perform PRF stages. Enter usernames separated by commas. Diagnostic users default to ISD members when left blank. Award authority defaults to ISD members and configured ISM approvers when left blank. Branch Manager approval remains required before assessment or forwarding.

Monitoring types

Fields for each monitoring type

One field per line: Label | type | options | *. Types: text, textarea, number, date, select. For select, list the choices separated by commas. Add * at the end to make a field required. Date and Branch are always included. ISRF is pre-filled with its standard fields and can be edited too (keep the labels Error type, Documents damaged and Problem details to keep showing existing data; leave the options of Error type blank to use the Error types list). A new monitoring with no fields yet uses the ISRF fields. Do not rename a field once records exist; add a new one instead.
Example: Vendor | text | * and Category | select | Hardware, Software, Network

Database export and migration (SQL Server)

Download your data as a SQL Server script (tables and INSERT statements) or a JSON backup. Attachment files stay in the Google Drive folder "IS PROJECTS Attachments"; their names and Drive IDs are exported in the Files table.

Transfer directly to SQL Server

Works only if your SQL Server is reachable from the internet and allows Google's connections. Otherwise use the .sql script. The password is used for this transfer only and is not saved.
